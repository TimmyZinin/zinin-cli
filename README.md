# ZININ CLI

**AI-инженер в твоём терминале.** Пилотируемый AI, не автопилот — управляй и понимай.

Авторский AI-харнес Тима Зинина: собственный REPL, мульти-LLM, ведёт за руку через установку Claude Code и Codex, учит, как устроен AI, пока ты работаешь.

## Установка — одна команда

**macOS / Linux:**
```sh
curl -fsSL https://zinin.ai/install | sh
```

**Windows (PowerShell):**
```powershell
irm https://zinin.ai/install.ps1 | iex
```

Без Node, без Homebrew — ставится один бинарь в PATH. Потом просто:
```sh
zinin
```

## Команды

| Команда | Что делает |
|---------|-----------|
| _(просто пиши)_ | разбор бизнеса, контент, автоматизации — обычным языком |
| `/setup` | проверит и поставит Claude Code / Codex |
| `/call` | позвать Тима на разговор (живой инженер, помощь с настройкой) |
| `/model` | сменить LLM (бесплатные / платные) |
| `/help` | меню |
| `/exit` | выход |

## Движок

Мульти-LLM с бесплатными моделями по умолчанию — ничего настраивать не нужно. Свой ключ OpenRouter (опционально, для прямого доступа):
```sh
export OPENROUTER_API_KEY=...
```

## `zinin ps` — что где происходит

На Маке `zinin ps` собирает локальные вкладки Terminal и newa по SSH. На newa
та же команда читает рабочие каталоги. Источники только читаются; ошибка или
таймаут одного источника не убирает другую машину из обзора.

```sh
zinin ps                         # последние 24 часа плюс все running
zinin ps --watch 5               # обновлять каждые 5 секунд
zinin ps --since 4h              # окно свежести: m / h / d
zinin ps --all                   # также старые и без известного времени
zinin ps --sources newa --json   # тот же фильтр, подробные доказательства
```

Обзор показывает блоки «Ждут решения владельца», «Работают сейчас», «Сданы»,
«Простаивают» в этом порядке. Внутри — самое свежее движение сверху.
В строке: машина, имя сессии, короткое описание или вопрос, время без движения
(мин/ч/дн), пометки. Каждая сессия занимает ровно одну строку: решение → работа
→ сдача → простой; running всегда остаётся в работе. Предыдущая сдача помещается
в хвост той же строки «сдано раньше: …». Колонки выровнены по экранной ширине;
описание и хвост сокращаются под ширину терминала (без TTY — 100 колонок).
Подробности доступны в JSON. Недоступный источник выводится отдельно:
«Недоступно: Мак/newa». Оценки по времени файла и неизвестная свежесть вопроса
объясняются общей сноской, а не повторяются в каждой строке. Исторические каталоги скрыты по умолчанию;
строка «ещё N старых скрыто — zinin ps --all» сообщает их число. Неизвестное
время у неработающей сессии тоже требует `--all`. Итог обеих машин считает ровно строки видимых блоков: работают, ждут решения,
сданы, простаивают. Время сдачи на этот счётчик не влияет. Имя строки Мака —
движок (claude/codex/kimi), иначе «окно N»; стабильный tty-ID остаётся в JSON
и принимается командой show.

Пример с вымышленными данными:

```text
Ждут решения владельца
newa  sample-choice  Вопрос: выбрать CSV?  7 мин
Работают сейчас
Мак  claude  Проверяет таблицу  4 ч
newa  sample-check  Проверяет импорт  2 мин
Сданы
newa  sample-export  СДАНО: экспорт проверен  12 мин
Простаивают
newa  sample-idle  Проверяет архив  1 ч · простаивает
ещё 8 старых скрыто — zinin ps --all
Мак: 1 работают, 0 ждут решения, 0 сданы, 0 простаивают · newa: 1 работают, 1 ждут решения, 1 сданы, 1 простаивают
```

### Описание и состояния

Описание newa берётся по порядку: первая содержательная строка TASK*.md →
последняя строка «СТАТУС:» REPORT-S0.md → последний заголовок `##` REPORT без
даты-префикса → последняя содержательная строка REPORT → первая содержательная
строка README.md/TO-S0.md. README допускается только при наличии строки с именем
этой сессии. Кодовые блоки, подписи, общий шаблон исполнителя, строки с двоеточием
на конце или короче 12 значимых символов пропускаются. Маркеры списков и даты в
начале убираются. Служебные строки контроллера `Turn N stopped:` не являются
описанием задачи или вопросом. Текст не пересказывается моделью: пробелы нормализуются, до 120
символов в JSON; в обзоре длина зависит от свободной ширины. Последний fallback —
имя папки с пометкой «(по имени папки)», `taskSource="directory-name"`.
Поле `taskSource` указывает файл и вид строки. На Маке источник — заголовок
вкладки (`terminal-title`); если Terminal не отдаёт название, показывается
номер вкладки. Управляющие последовательности удаляются из читаемого вывода.

JSON разделяет `liveness`, `activity`, `decision` и `lastSubmission`.
Доказательство содержит `text`, `source`, `atMs`; вопрос также `freshness`.
У живого newa-collector точная живость процесса и время последнего say
неизвестны: `liveness="unknown"`, `lastSayMs=null`. Содержимое status.json
не подменяет проверку процесса. Вопросы, блокеры и ожидание квитанции в TO
сохраняются при любой свежести; старая сдача не скрывает новый вопрос.

Для полезного обзора разрешены отдельно помеченные оценки по mtime status.json:

- `running` → работает; старше 20 минут → «возможно зависла».
- `idle` + последний неотвеченный запрос/пакет в TO → ждёт решения независимо
  от mtime; более поздняя датированная квитанция/«принято» в TO или REPORT
  закрывает запрос. Пакет узнаётся по packet_id/requested_receipt в JSON-блоке.
- Финальное «жду/ожидаю слова S0» в REPORT при idle → «сдано, ждёт слова»,
  после настоящих вопросов; running остаётся в работе.
- Для остальных сигналов: вопрос не раньше mtime status минус 20 минут → ждёт решения;
  берётся дата записи, а при её отсутствии — mtime TO.
- `idle` без такого вопроса + сдача → сдано; иначе «простаивает».
- `failed/timeout` → «ход остановлен» с `reason`, без утверждения об аварии.

`overviewGroup`, `possiblyStuck`, `stoppedReason` несут
`source="status-mtime"`, `confidence="estimate"`. Пороги заданы константами
`QUESTION_WINDOW_MINUTES`/`RUNNING_STALE_MINUTES` и подменяются опциями
collector. `--stuck-minutes N` отдельно меняет совместимый derived state
(по умолчанию Claude 20 минут, остальные 30); точные доказательства не меняет.
Проценты, модель, ошибки, версии и метрики остаются в JSON. Сам по себе текст
403 не доказывает исчерпание лимита; idle-глиф ✳ без спиннера не значит работу.

### Источники и установка remote-команды

Newa читает только верхний уровень `/home/agents/work/<name>/`: status.json,
meta.json, TO-S0.md, REPORT-S0.md, TASK*.md, README.md. Без symlink/hardlink,
вложенных каталогов, turns, tmux и проверки процессов. Входной файл ограничен
128 КиБ, число каталогов — 1024, TASK-файлов — 16; превышения и отказ чтения
отмечаются. На Linux разрешённые пути привязаны к открытым directory fd через
/proc/self/fd; на macOS — обычные пути с O_NOFOLLOW и проверкой dev/ino каталогов
и файлов до/после чтения. Root проходит realpath для системных symlink-предков
вроде /var, но symlink самого root отвергается. Сбор имеет конечный таймаут,
watch не запускает пересекающиеся сборы.

Mac читает все вкладки каждого окна Terminal: ASCII 9 между полями, ASCII 30
между записями, сырой tty `/dev/ttysNNN`. Contents читается по явному индексу
вкладки: `contents of tab tabIndex of w`. Ошибка отдельной вкладки даёт запись
с window-index и текстом ошибки в `machines[].warnings`; остальные сохраняются.
ID `mac-tab-ttysNNN` переживает перенос
вкладки в другое окно; без tty резервный window/index меняется при перестановке.
Счётчик «живых» означает наблюдаемые вкладки, не доказательство жизни движка.
Связь с проектом: tty → ps/lsof каталог запуска → запасной cwd статусной строки.
Хвосты Claude `~/.claude/projects/*/*.jsonl` читаются до 64 КиБ за последние
24 ч (`ZININ_PS_TRANSCRIPT_MINUTES`). Самая активная вкладка проекта получает
движение и ошибку; при нескольких сессиях одного проекта это эвристика.
Время не выдумывается для вкладки без transcript-фактов. Метрики Mac собираются
через memory_pressure/vm_stat и df. Для AppleScript нужен доступ к Terminal.

Remote-команда выбирается: `ZININ_PS_NEWA_CMD` → `~/.zinin/ps.json` → временный
встроенный путь к worker checkout. Закрепите собственный путь установки:

```json
{"newaCmd":["ssh","-o","BatchMode=yes","-o","ConnectTimeout=5","newa","/absolute/path/to/bun","/absolute/path/to/zinin-cli/src/repl.ts","ps","--sources","newa","--json"]}
```

Это шаблон путей, не команда установки. Обе стороны должны использовать E4:
сборщик добавляет `--all` к remote-команде и фильтрует полный JSON локально,
чтобы `--all`/`--since` работали одинаково. Проверяются типы, машина и структура
remote JSON; частичный отфильтрованный ответ отвергается. Команды запускаются
без shell, с лимитом вывода и таймаутом; SSH должен уже работать без пароля.
`version` и `machines[].version` позволяют сверить код обеих сторон,
`hidden_count` — количество скрытых строк. `--help` перечисляет флаги.

### Проверка

`bun test` выполняет тесты парсеров, raw tty/ASCII фикстур, разделения состояний,
ограниченного чтения, отказов/таймаутов, JSON, фильтров и обзора. На newa можно
проверить всё это и живой `/home/agents/work`. Исполнение нового AppleScript,
несколько живых вкладок в одном окне, перенос вкладки, доступ к Terminal и
совмещённый Mac+newa запуск требуют отдельной живой проверки на Маке. Фикстуры
её не заменяют. Сборщик не разворачивает код на другой машине автоматически.

## `zinin ps show` — подробности одной сессии

```sh
zinin ps show example-worker
zinin ps show newa:example-worker --json
zinin ps show claude --sources mac
zinin ps show mac-tab-ttys071 --sources mac
ssh newa /absolute/path/to/bun /absolute/path/to/zinin-cli/src/repl.ts ps show example-worker --sources newa --json
```

Команда ищет во всех наблюдаемых сессиях, включая скрытые фильтром 24 ч.
Сначала точное имя/ID, затем совпадение части имени. Для совпадений в разных
машинах используйте `newa:<id>` или `mac:<id>`. Имя движка может обозначать
несколько вкладок: тогда выводится список с точными ID, ничего не выбирается
автоматически. Нет совпадения и недоступный источник различаются. `--watch`
для show не поддерживается.

Newa показывает полное содержимое выбранного TASK-файла, либо полный текст
выбранного запасного описания, с источником; полный текущий вопрос; последнюю
сдачу с источником и временем; последние 15 содержательных строк REPORT-S0.md;
state/reason из status.json, движок и модель. Продолжение вопроса/сдачи до
следующего заголовка, метки времени или вопроса входит в подробности. Примеры
кода, подписи и служебные Turn stopped не становятся вопросом или отчётом.
При отсутствии даты/данных показывается «неизвестно»; состояние не пересчитывается
по тексту подробностей.

Для Мака выводятся заголовок вкладки, сырой `/dev/ttysNNN`, движок/модель,
каталог запуска по tty (запасной — cwd статусной строки), последние 15 непустых
строк экрана. Экран не считается доказательством приёмки результата. Точные
поля вопроса/сдачи на Маке могут оставаться неизвестными.

`--json` возвращает `query`, `status` (`found`, `ambiguous`, `not-found`,
`unavailable`), `sessions`, `machines`, `generatedAt`. У найденной сессии есть
`details`: `task {text,source}`, `question`, `submission`, `reportLines`,
`status`, `reason`, `terminal`. Короткие поля обзора остаются совместимыми.
При неоднозначности возвращаются строки совпадений без произвольной загрузки
подробностей одной из них. Текстовый вывод убирает управляющие escape-последовательности.

Чтение newa выполняет тот же collector: только разрешённые файлы верхнего
уровня, без symlink/hardlink, до 128 КиБ на файл, конечные таймауты. После
разрешения имени загружается только точно выбранная папка; вложенные каталоги
и пути из введённого имени не обходятся. Слишком большой/недоступный файл
помечается предупреждением, частичный текст не выдаётся за полный.

При запуске на Маке подробности newa запрашиваются через существующую SSH-команду.
Обе стороны должны поддерживать show: внутренний `--detail-id` передаёт точный
ID в base64url, чтобы имя не интерпретировалось удалённой оболочкой. Входящий JSON
подробностей проверяется по типам, размеру, длине хвостов и источникам;
неизвестные вложенные поля отбрасываются. Отказ/исчезновение сессии между двумя
чтениями даёт `unavailable`. Это read-only команда: task/accept/stop и управление
наблюдаемыми Terminal/newa сессиями не выполняются.

## Приватность

Телеметрия собирает только метаданные событий (никогда — текст твоих запросов). Отключить:
```sh
export ZININ_NO_TELEMETRY=1
```
