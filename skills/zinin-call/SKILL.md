# Запись на созвон + фиксация лида

Цель: превратить интерес в забронированный слот Calendly и доставить лид Тиму
в Telegram, чтобы он подхватил тёплый контакт.

## Алгоритм

1. **Собери лид одним коротким сообщением** (не допросом). Минимум:
   - Имя / как обращаться
   - Бизнес (что и для кого)
   - Задача в одной фразе (что хочет автоматизировать)
   - Контакт для связи (Telegram-ник или почта)
   Если что-то не дал — не настаивай, фиксируй что есть.

2. **Дай ссылку на Calendly** (всегда эта, кликабельная):
   `https://calendly.com/timzinin/30min`
   Скажи: «30 минут, без слайдов. Выбери слот — Тим подключится».

3. **Отправь лид Тиму в Telegram** через helper-скрипт проекта:
   ```bash
   node "$ZININ_HOME/src/send-lead.js" \
     --name "<имя>" --biz "<бизнес>" --task "<задача>" --contact "<контакт>"
   ```
   (ZININ_HOME экспортируется лаунчером. Скрипт шлёт в TG-чат Тима через Bot API
   или, как фолбэк, пишет лид в локальный файл leads/leads.jsonl.)

4. **Подтверди человеку**: «Готово — слот за тобой, я скинул вводные Тиму,
   он подключится с контекстом. До связи!»

## Тон
Тепло, без втюхивания. Сначала польза была дана в аудите — созвон это следующий шаг.
По-русски. Без частицы «не» в начале мыслей.

## Важно
Лид отправляется ТОЛЬКО когда человек явно согласился на созвон/контакт.
Не отправляй лид без согласия — это спам и нарушение доверия.
